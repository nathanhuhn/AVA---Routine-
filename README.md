# AVA Routine V1.7

Single-file mobile-first AVA Routine prototype.

## New in V1.7
- Existing routines continue to auto-save locally using the same AVA storage key.
- Settings now contains Data & Sharing.
- Download a full JSON backup and restore it later.
- Send a clean standalone HTML copy to another person.
- Send a standalone HTML copy seeded with your current routine setup (completion history is reset for the recipient).
- Shared copies use their own storage key, so the recipient's changes do not affect the sender.

Open `index.html` in a browser. For the most app-like experience, host the file over HTTPS and add it to the phone's home screen.
